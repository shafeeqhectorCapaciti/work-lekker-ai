# WorkLekker AI — Workplace Productivity Assistant

## Project Overview
**WorkLekker AI** is an integrated, AI-powered workplace productivity dashboard designed to help professionals automate everyday administrative and communication tasks. Built as part of the CAPACITI programme, the platform brings multiple AI tools together into a single, modern, and responsive interface while promoting responsible AI usage.

## Features Implemented
* **Smart Email Generator:** Creates polished workplace emails from brief bullet points with selectable tones (*Formal*, *Friendly*, and *Persuasive*).
* **Meeting Notes Summarizer:** Converts raw meeting transcripts into structured summaries highlighting key decisions, action items, and deadlines.
* **AI Task Planner / Scheduler:** Organizes daily to-do lists by urgency and importance into a prioritized, actionable schedule.
* **Editable Outputs & Copy Functionality:** Allows users to review, customize, and copy AI-generated drafts directly within the app.
* **Responsible AI Disclaimer:** Includes clear guidance reminding users to review AI outputs before sharing.

## Technologies & Tools Used
* **Platform & AI Engine:** Lovable AI
* **Frontend:** React, TypeScript, Tailwind CSS
* **Version Control:** Git & GitHub

## Setup Instructions
1. **Live Web App:** Access the hosted application directly via the published Lovable URL:`https://work-lekker.lovable.app`
2. **Run Locally:**
   ```bash
   git clone https://github.com/shafeeqhectorCapaciti/work-lekker-ai.git
   cd work-lekker-ai
   npm install
   npm run dev
   ```
