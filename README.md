# Work Lekker

Build a modern, responsive dark-mode SaaS web application called WorkLekker AI (by ShafeeqH) that helps professionals automate workplace tasks using Lovable AI.

Layout & Design:

Dark navy/slate theme (#0B0F19 background, #131826 cards, indigo/purple accent buttons).

Left sidebar navigation with links for: Dashboard, Smart Email Generator, Meeting Notes Summarizer, and AI Task Planner.

Top banner with a subtle Responsible AI disclaimer: "AI-generated content may require human review."

Dashboard View: A hero banner introducing WorkLekker AI with quick-start buttons and a clean 3-column grid of cards linking to the 3 productivity tools. Do NOT include any metric or stat cards.

Interactive Features (Connect all 3 to real AI using Lovable AI, with editable output textareas and Copy buttons):

Smart Email Generator: Inputs for Recipient, Subject/Context, Key Points, and a Tone selector (Formal, Friendly, Persuasive).

Meeting Notes Summarizer: Textarea for raw meeting notes that outputs structured Decisions, Action Items, and Deadlines.

AI Task Planner: Input for tasks with Urgency/Importance tags that generates a prioritized daily schedule.

This project was built with [Lovable](https://lovable.dev).
